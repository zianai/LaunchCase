# LaunchCase tool design brief

项目：从原始证据到内部产品草稿的决策工作台。
受众：跨境消费品产品负责人，在反复查证、比较和审批时使用。
气质：沉着、务实、有档案感；不要：营销式兴奋。
参考：交接包的信息架构与证据/推断/事实分离，未提供现有视觉品牌。
反参考：聊天首页、等大指标卡片墙、紫色渐变、虚构市场数字。
首屏任务：看清 Case 当前关卡与下一步；主行动“创建产品 Case”。

Scope: full new workbench, on codex/launchcase-v1 local branch. The user's explicit
independent implementation request and handoff allow a pending human baseline.
Therefore selection/token confirmation defaults of the aesthetic Skill are deferred,
not represented as received. Two rendered directions will be retained; provisional
choice is the warm paper / dark green case ledger. Alternative: cool technical lab.
Accessibility, error states, quoted sources and approval semantics outrank decoration.
