# LaunchCase → CreativeEngine 1.0.0

`fixtures.json` is a frozen safe synthetic receipt corpus. SHA256SUMS binds its bytes. The consumer test reads only this repository; CI does not import CE, TradeCase, or coordinator implementation. Additive unknown fields are compatible. Required scope IDs, explicit USD zero cost, independent QA status/check arrays, original identity and SHA-256 are validated at the application boundary. Missing QA, unknown cost, nonfinite/bool/string costs, wrong financial units and mismatched project/batch reject; ambiguous submitted receipts remain reconciling. Vision skipped is not semantic pass and is never asset approval.

Any breaking change requires another version directory. The actual Node HTTP probe is a separate integration check; the fixture is never business data, operator authorization or provider quality evidence.
